## 🧪 Quick Test Steps

### 1. Open the Application
```
http://localhost:8080
```

### 2. Test File Upload
1. Click "Supplier Evaluation" in sidebar
2. Find blue "Upload CSV" section
3. Upload CSV (minimum: `supplier_id` column)
4. Select model: Neural Network
5. Click "Upload & Evaluate"
6. ✅ See results!

### 3. Test AHP Analysis  
1. Click "Decision Support"
2. Select "AHP" method
3. Adjust sliders (e.g., Quality vs Risk = 6)
4. Click "Run AHP Analysis"
5. ✅ See rankings with consistency ratio!

### 4. Test Bias Detection
1. Click "Ethics & Compliance"
2. Enter: `years_in_business`
