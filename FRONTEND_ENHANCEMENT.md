## 📋 Usage Examples

### Add AOS animations to elements:
```html
<div data-aos="fade-up" data-aos-duration="800">
    Content here
</div>
```

### Use enhanced classes:
```html
<button class="btn btn-primary hover-lift">Click Me</button>
<div class="card glass-effect">Glass card</div>
<h1 class="gradient-text">Gradient Title</h1>
```
